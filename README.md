# XYLOFY AI Data Science Internship

This repository contains the weekly tasks completed as part of the XYLOFY AI Data Science Internship Program.

## Week 1 - House Price Prediction
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model building using:
  - Linear Regression
  - Polynomial Regression
  - Random Forest Regression
- Model evaluation
- Business insights and recommendations

---

## Week 2 - Employee Attrition Prediction
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model building using:
  - Logistic Regression
  - Random Forest Classifier
  - Gradient Boosting Classifier
- Model evaluation using:
  - Precision
  - Recall
  - F1-Score
  - ROC-AUC
- Feature importance analysis
- HR recommendations and business insights
